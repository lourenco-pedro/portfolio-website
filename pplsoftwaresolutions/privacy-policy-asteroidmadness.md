# Privacy Policy

Last updated: 2026-06-25

This Privacy Policy explains what data Asteroid Madness collects, how it is used, and where it is stored.

## Summary

Asteroid Madness does not collect personal information such as your real name, email address, phone number, address, or payment details.

The only player-provided information used for the online leaderboard is:

- A nickname chosen by the player
- The player’s score

The game also uses a generated leaderboard user ID to identify the player’s entry on the leaderboard service. This identifier is not a real-world identity and is used only for leaderboard functionality.

## Data Collected

### 1. Leaderboard nickname

When you choose to upload a score, the game asks for a nickname. Use any name you want; a real name is not required.

### 2. Score

Your score is sent to the leaderboard service together with the nickname.

### 3. Generated leaderboard user ID

The leaderboard system creates a unique user ID so the game can fetch, update, or delete your own leaderboard entry.

Depending on the leaderboard configuration, this ID may be saved locally on your device using either PlayerPrefs or a local file so the game can recognize you again later.

### 4. Local best score

The game stores your best score locally on your device so it can display your personal best. This value is not used as a real-world identifier and is not meant to identify you personally.

## What Is Not Collected

Asteroid Madness does not intentionally collect:

- Real name
- Email address
- Phone number
- Home address
- Age or date of birth
- Contacts
- Location data
- Advertising identifiers
- Analytics or telemetry data
- Crash reports

## How Data Is Used

- Nickname and score are used to display and maintain the online leaderboard.
- The generated user ID is used to recognize the player’s own leaderboard entry.
- The local best score is used only to show your personal best within the game.

## Data Sharing

Leaderboard submissions are sent to the leaderboard service operated by the game’s leaderboard provider. The game itself does not sell personal data or use it for advertising.

Like any online service, the leaderboard service may receive standard technical information needed to process a web request, such as network metadata. That information is handled by the service provider and is not intentionally collected by the game as player profile data.

## External Services

Asteroid Madness currently makes network requests to the following external services:

- `lcv3-server.danqzq.games` for leaderboard authorization, score upload, leaderboard retrieval, and version checks for the Leaderboard Creator tool

These requests are used only for the features described above.

## Local Storage

The game may store the following locally on your device:

- Best score
- Generated leaderboard user ID, if leaderboard saving is enabled in the leaderboard configuration

You can remove locally stored data by clearing the game’s local save data or resetting the game installation data on your device.

## Children’s Privacy

Asteroid Madness is not designed to collect personal information from children. If a child uses the leaderboard, only a nickname and score are requested for score submission.

## Changes To This Policy

We may update this policy if the game’s data collection behavior changes, such as adding analytics, account systems, or additional online features.

## Contact

If you have questions about this policy, contact the game’s developer or publisher through the official project or store page.
